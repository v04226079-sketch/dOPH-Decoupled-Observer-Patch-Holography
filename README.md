# Decoupled Observer Patch Holography (dOPH)

**Декуплированная Голография Наблюдательных Патчей**

Улучшенная версия Observer Patch Holography Бернхарда Мюллера с введением четвёртой аксиомы — **Декуплинг** — как локального механизма исправления ошибок.

### Основные материалы
- [Финальный анализ и тестирование (апрель 2026)](docs/dOPH_Final_Analysis_Russian.tex)

### Результаты тестирования
В папке [`code/`](code/) находятся скрипты с результатами Monte-Carlo тестов:

- [`monte_carlo_basic.py`](code/monte_carlo_basic.py) — базовый тест
- [`doph_test_results.py`](code/doph_test_results.py) — вывод результатов
- [`doph_results_table.py`](code/doph_results_table.py) — красивая таблица результатов

### Ключевые выводы (апрель 2026)
- На оригинальной SPARC (175 галактик): **стабильность 97.7%**
- На 4000 синтетических галактиках: **стабильность 85.5%**
- На 10 000 синтетических галактиках: **стабильность 79.0%**
- Лучшие результаты — на относительно спокойных системах (Млечный Путь)
- Главный вызов — масштабируемость при росте морфологического разнообразия

### Цели проекта
- Разработка открытой численной модели dOPH
- Честное сравнение с MOND и другими альтернативами
- Тестирование на реальных данных SPARC и BIG-SPARC (когда данные будут доступны)

*Science is infinite. As long as there is something to test — we test it.*
