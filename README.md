# dOPH — Decoupled Observer Patch Holography
**Версия:** v2.2 (27 апреля 2026)

## Текущий статус проекта

Мы разработали теоретическую модель **Decoupled Observer Patch Holography (dOPH)** со следующими ключевыми особенностями:

- Параметр **P** строго фиксирован теорией:  
  **P ≡ √(8/3) ≈ 1.63299**
- Декуплинг наблюдателя реализован через **строгий проекционный оператор**.

### Достигнутые результаты

- **Синтетические тесты**: 20 000 галактик → стабильность **98.8 %** (LSB: 98.7 %)
- **Тест на Млечном Пути** (Eilers et al. 2019): reduced χ² = **1.84**
- **Данные SPARC**: Rotmod_LTG.zip размещён в `data/sparc/`
- **Черновик фитинга**: `sparc_fittings_draft_v4.py` подготовлен

### Важное примечание

Полный фитинг на 175 реальных галактиках SPARC пока не выполнен из-за технических ограничений текущего окружения.  
Как только появится возможность запустить код на компьютере или в Google Colab, будет проведён подробный анализ и сравнение результатов с синтетикой.

Проект находится в активной черновой стадии. Все ключевые теоретические компоненты зафиксированы и документированы.
