# Decoupled Observer Patch Holography (dOPH)

**Декуплированная Голография Наблюдательных Патчей**

Улучшенная версия Observer Patch Holography (OPH) Бернхарда Мюллера с аксиомой декуплинга и комбинированными механизмами стабилизации (emergent gravity + фазовый консенсус + демпфирование + инерция).

### Цели проекта
- Разработка и тестирование dOPH как минималистской emergent теории физики
- Monte-Carlo тесты на синтетических и реальных данных (SPARC, BIG-SPARC)
- Прямое сравнение с MOND и другими альтернативами тёмной материи
- Открытая и воспроизводимая наука

### Структура репозитория
- `docs/` — LaTeX-документы и статьи
- `code/` — Python-код (загрузка SPARC, модель патчей, Monte-Carlo)
- `results/` — таблицы и графики результатов
- `data/` — ссылки на данные SPARC (файлы не храним)

### Текущий статус (апрель 2026)
- Проведены Monte-Carlo тесты до 10 000 синтетических галактик
- Разработана комбинированная модель стабилизации
- Подготовлен финальный анализ на русском языке
