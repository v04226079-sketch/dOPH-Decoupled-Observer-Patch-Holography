# Decoupled Observer Patch Holography (dOPH)

**Улучшенная версия Observer Patch Holography с механизмом decoupling**

### Основная идея

dOPH добавляет к оригинальной Observer Patch Holography ключевой механизм **decoupling** — локальное исправление рассогласований на пересечениях патчей. Это позволяет модели лучше описывать реальные кривые вращения галактик.

### Ключевые особенности

- Фиксированный параметр **P = √(8/3) ≈ 1.63299**
- Строгий оператор декуплинга (F_decouple)
- Двухкомпонентная модель (газ + звёзды) с плотностно-зависимыми весами
- Адаптивное усиление в низкоплотных областях
- Scale-dependent эффект (зависит от радиуса и барионной массы системы)

### Результаты

**На синтетических данных (20 000 галактик):**
- Средняя стабильность патчей: **97.9–98.8%**

**На реальных данных SPARC (91 галактик):**
- Средний reduced χ²_red ≈ **1.5–1.7** (лучше или на уровне классической MOND \~1.98)
- Подробные результаты и таблицы → [RESULTS.md](RESULTS.md)
