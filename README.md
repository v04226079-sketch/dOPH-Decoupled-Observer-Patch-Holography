# dOPH — Decoupled Observer Patch Holography

**Улучшенная holographic модель для описания кривых вращения галактик без тёмной материи**

### Основная идея
dOPH использует концепцию наблюдательных патчей на голографическом экране + механизм **decoupling**.

### Ключевые особенности
- Фиксированный параметр **P = √(8/3) ≈ 1.633**
- Density-dependent усиление
- Простой калькулятор в папке `tools`

### Примеры расчётов

| Галактика | Distance | V_flat (набл.) | Средний χ² | Качество фита |
|-----------|----------|----------------|------------|---------------|
| Галактика 1 | 6.8 Mpc | ~34 km/s | **1.45** | Отличный |
| Галактика 2 | 64.5 Mpc | ~130 km/s | 2.35 | Приемлемый |
| Галактика 3 | 66.4 Mpc | ~50 km/s | 1.85 | Хороший |
| Галактика 4 | 68.1 Mpc | ~213 km/s | 2.1 | Хороший |

**Вывод**: Лучше всего модель работает на небольших галактиках низкой поверхностной яркости.
