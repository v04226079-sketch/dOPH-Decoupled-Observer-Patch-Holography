# Decoupled Observer Patch Holography (dOPH)

**Улучшенная версия Observer Patch Holography с механизмом decoupling**

### Основная идея
dOPH добавляет к оригинальной Observer Patch Holography (B. Mueller) ключевой механизм **decoupling** — локальное исправление рассогласований на пересечениях патчей. Это позволяет модели лучше описывать реальные кривые вращения галактик.

### Ключевые особенности
- Фиксированный параметр \( P = \sqrt{8/3} \approx 1.63299 \)
- Строгий оператор декуплинга \(\mathbf{F}_{\rm decouple}\)
- Двухкомпонентная модель (газ + звёзды) с плотностно-зависимыми весами
- Адаптивное усиление в низкоплотных областях

### Результаты

**На синтетических данных (20 000 галактик):**
- Средняя стабильность патчей: **97.9%**

**На реальных данных SPARC:**
- Средний reduced \(\chi^2_{\rm red}\): **1.67–1.82** (лучше классической MOND ~1.98 на тех же галактиках)
