# dOPH — Decoupled Observer Patch Holography
**Версия:** v2.2 (27 апреля 2026)

## Текущий статус

**Ключевые достижения:**

- Параметр **P** строго фиксирован теорией:  
  **P ≡ √(8/3) ≈ 1.63299**

- Декуплинг наблюдателя через строгий проекционный оператор.

**Тесты:**

- **Синтетика**: 20 000 галактик → стабильность **98.8 %** (LSB: 98.7 %)
- **Млечный Путь** (Eilers et al. 2019): reduced χ² = **1.84**
- **SPARC** (реальные данные, 175 галактик): средний reduced χ² = **2.47**, стабильность **96.6 %**

Модель показывает хорошую устойчивость на синтетике и приемлемое согласие с реальными ротационными кривыми.  
SPARC-результаты указывают на необходимость дальнейшей доработки holographic patch term для LSB-галактик.

## Основные файлы

- `doph_model_improved.py` — основная модель
- `code/doph_reproducible_test.py` — тест на 20 000 галактик
- `code/sparc_fittings_draft_v3_auto.py` — черновик фитинга SPARC
- `dOPH_Final_April2026.tex` — основной документ

Проект находится в активной черновой стадии. Все результаты получены с фиксированным теоретическим параметром P.
